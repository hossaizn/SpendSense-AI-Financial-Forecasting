# SpendSense AI - Financial Forecasting


A machine learning model built using Gradient Boosting (GBM) in R Studio to predict client spending based on historical spend data and key performance indicators (KPIs). The model was deployed via Shinyapps.io to enable real-time financial analytics.

**Take a look at the app UI:** [SpendSense AI - Live Demo](https://zulqarnayan-toyota.shinyapps.io/my_shiny_app/)

---

## Key Features
- Uploads CSV/Excel files for forecasting
- Uses Gradient Boosting Machine (GBM) for predictions
- Allows users to input custom forecast periods
- Provides real-time spending trend analysis
- Deployed on Shinyapps.io for interactive analytics

---

## Technical Stack
- **R Studio**
- **Gradient Boosting Machine (GBM)**
- **Feature Engineering**
- **Shiny (for UI)**
- **Shinyapps.io (for deployment)**

---

## How It Works
1. User uploads a CSV or Excel file with past spending data
2. The model processes the data and applies feature engineering
3. GBM is used to forecast spending trends
4. The forecast results are displayed in an interactive UI

## Challenges & Learnings
